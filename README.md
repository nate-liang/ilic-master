# Ivy Investment Competition website

Eight static HTML pages, shared styles.css and script.js. No dependency installation or compilation is required. Serve the project with `python3 -m http.server 8765 --bind 127.0.0.1`, then open http://127.0.0.1:8765. Publish the HTML, CSS, JavaScript, original image files, and assets folder together using the existing static host.

The redesign retains the existing competition information and image assets, adds the supplied unmodified IIC logo variations, and updates the name to Ivy Investment Competition. See DESIGN.md for typography, palette, layout, and animation conventions. Google Fonts requires internet access; local fallback fonts are provided.
